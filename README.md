## 🌟 프로젝트 소개

**norosi(노로시)**는 봉화(狼煙, 연기 신호)를 뜻하며, 혼잡한 디스코드 서버에서 관리자와 유저 모두에게 가장 명확하고 따뜻한 이정표가 되어주고자 기획되었습니다. 

단순한 기능 나열을 넘어, **GUI 대시보드 인터랙션**, **Firebase 하이브리드 캐시 저장소**, **Discord Audio DAVE 최신 암호화 엔진**, **VM 터미널 실시간 스트리밍** 등 최상위 엔터프라이즈급 안정성을 기본 내장하고 있습니다.

## ✨ 핵심 기능

### 1. 🧭 올인원 마스터 대시보드 (`/대시보드`, `/메뉴`)
- 명령어 타이핑 없이 드롭다운 탭과 버튼 클릭만으로 봇의 모든 기능(83개 슬래시 명령어 · 129종 세부 기능 · 27종 `!` 단축어)을 한눈에 조작하는 인터랙티브 GUI 허브
- 홈, 프로세카, 원신, 스타레일, 통합 낚시, 통합 경제·농장·펫·요리, 일정·라이프, 음악·플리, 관리·역할·티켓·비상방어, 게임·타인의인생·릴레이소설, 서버통계 **11대 탭** 즉각 전환 지원

### 2. 🎮 프로젝트 세카이(Project SEKAI) 가챠 & 컬렉션
- **4대 배너 & 시각별 세카이 로테이션:** 🌟일반 · 🎊컬러풀 페스티벌(★4 2배) · 🎂생일 한정 · 👗3D 의상 & 악세서리 픽업 가챠 및 KST 시간대별 세카이 유닛·속성 자동 픽업
- **카드 보관함 & 필터/정렬:** 유닛별·캐릭터별 필터, 강화순/성급순/보유수순/최근획득순 정렬, 각성 전·후 일러스트 전환, 마스터 랭크(✦0~5), 3D 의상실 & 어나더 컬러, 세카이 라이브, 마이세카이
- **💎 중복 카드 일괄 환전 & 도감/미래시:** 등급별(★4: 100💎, 생일: 60💎, ★3: 25💎, ★2/★1: 5💎) 원클릭 환전 및 2026~2027 한섭 미래시 캘린더(`/미래시`)

### 3. 🌠 원신(Genshin Impact) & 🚄 붕괴: 스타레일(Honkai: Star Rail) 실시간 DB 연동
- **원신 (`/원신 기원`, `/원신 성유물`):** 5대 배너(캐릭터①·②/신의 주조 무기/상시/성유물 비경), 90/80 천장 & 포착된 광휘, 운명의 궤도, KST 시각별 원소·무기·성유물 로테이션, 성유물 +20강화·환성·축성의 엘릭서 제작, 페이몬 상점, 4인 원소 공명 파티
- **붕괴: 스타레일 (`/스타레일 워프`, `/스타레일 유물`):** 5대 배너(캐릭터①·②/빛의 자취 75:25 광추/상시/침식된 터널 유물), 상시 300회 5성 선택권, KST 시각별 운명의 길·속성·유물 로테이션, 유물 +15강화·만능 합성기·자가 조형 레진 제작, 별빛·헤르타 상점, 4인 개척 편대

### 4. 🎣 통합 낚시 시스템 — 호수·강·바다 36,700종 (`/낚시`)
- **글로벌 실제 어종 36,700종 DB:** 🏞️호수·🌊강·⚓바다 및 13개 세부 수역 탐사, KST 낮/밤·날씨·피딩타임 연동 입질 미니게임 & 포획 인증서 카드(cm·kg·희귀도)
- **가방 확장·다중 잠금·수족관·랭킹:** 낚시 가방(기본 180칸→최대 2,000칸) 확장 상점 및 다중 선택 🔒 잠금/해제·일괄 판매, 프라이빗 어항(최대 20칸), 낚싯대 6티어·릴 5티어·그물 5티어, `/낚시 랭킹` (`!낚시랭킹`) 서버 대물 랭킹 보드

### 5. 💳 통합 경제 · 프로필 카드 PNG · 🌾 농장·펫·요리 라이프 (`/프로필카드`, `/경제`, `/생활`)
- **고해상도 통합 프로필 카드 PNG (`/프로필카드`):** 출석·크리스탈·골드·오시·프세카/원신/스타레일/낚시/생활 지표를 한 장의 그래픽 카드로 렌더링 & 칭호/업적 배지 장착
- **크리스탈 송금 & 통합 자산 랭킹 (`/경제`):** 유저 간 크리스탈 안전 송금(수수료 5% · 일일 상한 5,000💎) 및 순자산·크리스탈·낚시골드 통합 랭킹
- **개인 농장 · 길드 공동 농장 · 펫 · 생선 요리 (`/생활`):** 작물 재배, 서버 협동 농장, 6종 펫 육성, 낚시 어종 요리 버프(쿨타임 감소·희귀어 확률·골드·출석 보너스)

### 6. 🎫 1:1 문의 티켓 & 🛡️ 서버 보안·커뮤니티 유틸리티 (`/티켓`, `/비상모드`, `/고정메시지`, `/릴레이소설`)
- **1:1 문의 티켓 스튜디오 (`/티켓`):** 버튼 클릭 즉시 비공개 채널/스레드 개설, 담당자 배정·멤버 추가, 종료 시 전체 대화록 `.txt` 자동 아카이브
- **커뮤니티 관리 & 협동 문학:** 하단 고정 메시지(`/고정메시지`), 긴 URL 자동 정리(`/링크미리보기`), 레이드·스팸 자동 감지 및 원클릭 서버 잠금(`/비상모드`), 서버 협동 `/릴레이소설`

### 7. 🎵 스마트 고음질 음악 & 플레이리스트 스튜디오
- **다양한 플랫폼 지원:** YouTube, Spotify, SoundCloud, 직링크 MP3 스트리밍 및 외부 플레이리스트 링크 통째로 가져오기(`/플리가져오기`)
- **DAVE 음성 엔진 & 실시간 리모컨:** Discord 최신 종단간 암호화(DAVE E2EE) 대응, 음성채널 순차 자동재생, 배속 조절(`0.5x~2.0x`), 헤드셋 청각차단 제어, 880Hz 오디오 자가진단

### 8. 📅 D-Day 전광판 & 라이프케어 허브
- **D-Day 실시간 전광판:** 음성/텍스트 채널 이름으로 D-Day 자동 카운트다운 갱신 및 나만의 타임캡슐 `/비밀디데이`
- **자동 알림 & 생일 축하:** 지정 시간에 기념일/시험 D-Day 및 서버원 생일 축하 메시지 발송(+500💎)
- **뽀모도로 집중모드 & 하드코어 스터디:** 맞춤 집중/휴식 타이머, 음성채널 자동 음소거 제어, 은하수 잔디 심기(`/오늘목표`)

### 9. 🎭 반응역할 & 🖥️ VM 서버 터미널 브릿지 & 감사 로깅 & AI 세카이 대화
- **반응역할 & 커스텀 버튼 패널:** 이모지 반응역할 스튜디오 및 맞춤 역할 버튼 패널 제작(`/반응역할`, `/역할버튼제작`)
- **실시간 콘솔 전송(요약/상세 모드) & GitHub 배포 알림:** `/무로시로그`, `/터미널로그채널`, `/깃허브연동`으로 부팅·런타임 로그를 **요약 버전(Summary)** 또는 **상세 버전(Detailed)**으로 전환하고 커밋 푸시 알림을 실시간 수신
- **7대 서버 감사 이벤트 로깅 & 활동 통계 & AI 대화:** 입퇴장/수정/삭제/음성/역할 로깅, `/서버통계`, `/유저정보`, 프로세카 26인 페르소나 Gemini 대화(`/인공지능대화`)

## 🚀 빠른 시작 가이드

### 1. 사전 요구사항
- **Python:** 3.10 이상
- **외부 유틸리티:** `ffmpeg`, `yt-dlp` (음악 재생 시 필요)
- **Git**

### 2. 저장소 클론 및 패키지 설치
```bash
# 1. 저장소 클론
git clone https://github.com/alyagsosiji/norosi.git
cd norosi

# 2. 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 필수 패키지 설치
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. 환경 변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 아래 양식에 맞추어 값을 입력합니다:

```env
# [필수] 디스코드 봇 토큰 (Discord Developer Portal에서 발급)
DISCORD_TOKEN="your_bot_token_here"

# [선택] 봇 관리자 유저 ID (우클릭 -> ID 복사)
BOT_OWNER_ID="123456789012345678"

# [선택] Spotify 추천 음악 API (Spotify Developer Dashboard)
SPOTIPY_CLIENT_ID=""
SPOTIPY_CLIENT_SECRET=""

# [선택] Firebase Realtime Database 연동 (원격 클라우드 백업용)
# GCP 로컬 디스크 환경에서는 비워두셔도 로컬 캐시(ddays_data.json)로 안전하게 작동합니다.
FIREBASE_DB_URL=""
FIREBASE_SECRET=""

# [선택] 웹서버 포트 (Render / 헬스체크용)
PORT="10000"
```

### 4. 봇 실행
```bash
python3 bot.py
```

봇이 켜지면 관리자 권한이 있는 디스코드 채널에서 `!싱크`를 입력하여 슬래시 명령어를 즉시 동기화해 주세요.
