## 🌟 프로젝트 소개

**norosi(노로시)는** 봉화(狼煙, 연기 신호)를 뜻하며, 혼잡한 디스코드 서버에서 관리자와 유저 모두에게 가장 명확하고 따뜻한 이정표가 되어주고자 기획되었습니다.

복잡하게 흩어져 있던 수십 개의 슬래시 명령어를 **`/설정`** 과 **`/도움말`** 단 2개로 일원화하고, **컴포넌트 V2 스타일 계층형 내비게이션(일반 · 고급 · 미니게임 · 개인 + 뒤로가기 + 15페이지 통합 페이지네이션 & 번호 바로가기 버튼)**, **개인 커스텀 즐겨찾기 단축바**, **권한 3단계 완벽 분리(일반 이용자 · 서버 관리자 · 봇 주인)**, **Firebase 하이브리드 비동기 캐시 엔진**, **Discord Audio DAVE E2EE 암호화 엔진** 등 최상위 엔터프라이즈급 안정성과 반응속도를 기본 내장하고 있습니다.

## ✨ 핵심 기능

### 1. ⚙️ 컴포넌트 V2 통합 설정 허브 (`/설정`) & 맞춤형 가이드 (`/도움말`)
- **슬래시 명령어 2종 완전 통합 (`/설정`, `/도움말`):** 복잡한 명령어 입력 없이 `/설정` 하나로 90개 전체 기능을 버튼과 모달만으로 막힘없이 조작합니다. (`!설정`, `!대시보드`, `!메뉴`, `!즐겨찾기` 등 기존 `!` 접두사 단축어도 완벽 호환)
- **컴포넌트 V2 계층형 UI & 15페이지 통합 페이지네이션:**
  - **1단계 (홈):** `[🌐 일반]` · `[⚙️ 고급]` · `[🎮 미니게임]` · `[👤 개인]` 4대 카테고리 버튼 + **⭐ 나만의 홈 즐겨찾기 단축바(최대 5개 커스터마이징)** + 빠른 실행 드롭다운 + 통합 페이지네이션(`1~15p`)
  - **2단계 (카테고리 내부):** 카테고리별 세부 기능 버튼(페이지당 6개) + `[⬅️ 뒤로]` + `[◀ / 📄 현재·통합 / ▶]` + **직접 페이지 번호 점프 버튼**
  - **3단계 (세부 제어판):** 도감·랭킹·티켓·픽업·백업·초기화 등 하위 컨트롤 패널 + `[⬅️ 뒤로]` + `[🏠 설정 홈]`
- **권한 3단계 엄격 분리:** **일반 이용자** (`👤일반`), **서버 관리자 전용** (`🛡️관리자`), **봇 주인 전용** (`👑봇주인`) 권한을 UI 배지와 서버 측 이중 검증으로 철저히 구분합니다.

### 6. 🎫 1:1 문의 티켓 · 🗓️ 예약 이벤트 RSVP · 🔊 임시 음성방 · 🔍 이모지 업스케일 · 🛡️ 서버 보안
- **🗓️ 예약 이벤트 신청표 (RSVP & 자동 리마인드):** `✅ 참가` · `🤔 보류` · `❌ 불참` 원클릭 집계, 정원 초과 시 대기열 등록 및 빈자리 발생 시 자동 승격, 시작 15분 전 참가 확정자 자동 리마인드 알림 (`!이벤트`)
- **1:1 문의 티켓 스튜디오:** 버튼 클릭 즉시 비공개 채널/스레드 개설, 담당자 배정·멤버 추가, 종료 시 전체 대화록 `.txt` 자동 아카이브
- **임시 음성방 자동 생성기 (Join-to-Create):** 로비 채널(예: `➕ 방 만들기`) 입장 시 즉시 개인 음성방을 생성·이동시키고, 음성방 내 **방 제목 변경·인원 제한(0~99명)·방 잠금·방 숨김·초대·강퇴·방장 위임 리모컨** 제공 및 전원 퇴장 시 자동 삭제
- **커스텀 이모지 160×160 WebP 업스케일 & CDN ([Kamilake/emote-cdn-rust](https://github.com/Kamilake/emote-cdn-rust) 가이드 준수):**
  - **투명 캔버스 여백 없이** 원본 종횡비를 100% 유지하며 `160×160` 박스 내 최대 크기(`Lanczos3`)로 리사이징 후 정적/애니메이션 `WebP` 포맷으로 변환
  - **모바일 & 데스크탑 종횡비 완벽 호환:** `200 OK` 검증된 WebP CDN 마스킹 언펄(`[⠀](url)`)을 통해 모바일에서도 화면 가로가 꽉 차지 않고 스티커 크기(`160×160`)와 원본 종횡비·애니메이션을 그대로 유지
  - **24시간 인메모리 캐시 & 내장 HTTP CDN:** `50,000` 엔트리 24h TTL 캐시, SHA-1 약한 ETag(`W/"..."`), 선택적 HMAC-SHA256 서명(`SIGNING_KEY`), `/emoji/{id}` · `/e/{id}.webp` · `/sticker/{id}` · `/s/{id}.webp` 엔드포인트 내장 및 `:x:`(❌) 반응 삭제 지원
- **커뮤니티 관리 & 협동 문학:** 하단 고정 메시지, SNS 미리보기 보정·추적 태그 제거, 레이드·스팸 자동 감지 및 원클릭 서버 잠금, 서버 협동 릴레이 소설

## 🚀 빠른 시작 가이드

### 1. 사전 요구사항
- **Python:** 3.12.3 권장 (3.10 이상 호환)
- **외부 유틸리티:** `ffmpeg`, `yt-dlp` (음악 재생 시 필요)
- **Git**

### 2. 저장소 클론 및 패키지 설치
```bash
# 1. 저장소 클론
git clone https://github.com/alyagsosiji/norosi.git
cd norosi

# 2. 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 필수 패키지 설치
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. 환경 변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 아래 양식에 맞추어 값을 입력합니다:

```env
# [필수] 디스코드 봇 토큰 (Discord Developer Portal에서 발급)
DISCORD_TOKEN="your_bot_token_here"

# [선택] 봇 주인(소유자) 유저 ID (우클릭 -> ID 복사)
BOT_OWNER_ID="123456789012345678"

# [선택] emote-cdn-rust 외부 CDN 주소 및 HMAC-SHA256 서명 키
# 미설정 시에도 내장 160x160 WebP 리사이저(포트 10000/53292) 및 공개 WebP CDN 폴백으로 자동 작동합니다.
EMOTE_CDN_BASE_URL="https://cdn.kamibot.app"
SIGNING_KEY=""

# [선택] Spotify 추천 음악 API (Spotify Developer Dashboard)
SPOTIPY_CLIENT_ID=""
SPOTIPY_CLIENT_SECRET=""

# [선택] Firebase Realtime Database 연동 (원격 클라우드 백업용)
# 로컬 디스크 환경에서는 비워두셔도 로컬 캐시(ddays_data.json)로 안전하게 작동합니다.
FIREBASE_DB_URL=""
FIREBASE_SECRET=""

# [선택] 웹서버 포트 (헬스체크 · GitHub 웹훅 · 내장 Emote CDN)
PORT="10000"
```

### 4. 봇 실행
```bash
python3 bot.py
```

봇이 켜지면 디스코드 채널에서 `/설정` 또는 `/도움말`을 바로 사용할 수 있으며, 수동 즉시 동기화가 필요한 경우 봇 소유자 계정으로 `!싱크`를 입력하면 즉시 반영됩니다.

## 🔍 이모지 업스케일 CDN (`emote-cdn-rust` 가이드 호환)

`cogs/emoji_upscale.py` 모듈은 [Kamilake/emote-cdn-rust](https://github.com/Kamilake/emote-cdn-rust) 프로젝트의 아키텍처와 가이드를 준수하여 구현되었습니다:

1. **투명 여백 없는 160×160 종횡비 유지 리사이징:**
   - 투명 캔버스 패딩을 사용하지 않고, 원본 이모지·스티커의 가로세로 비율(`aspect_ratio = width / height`)을 100% 보존하여 `160×160` 박스 내 최대 크기로 `Lanczos3` 리사이징 후 `WebP`(정적 및 애니메이션 WebP)로 인코딩합니다.
2. **모바일 & 데스크탑 종횡비 완벽 호환:**
   - 파일 첨부(`attachments`) 시 모바일 화면 가로 100%로 늘어나는 현상을 방지하기 위해, `HTTP 200 OK`가 검증된 `.webp` CDN 마스킹 링크(`[⠀](url)`) 언펄 방식을 사용하여 모바일과 데스크탑 모두에서 정확한 스티커 크기(`160×160` 박스)와 원본 종횡비를 유지합니다.
3. **내장 HTTP CDN 엔드포인트 (포트 `10000` 및 `53292`):**
   - `GET /healthz` — 서버 상태 확인 (`ok`)
   - `GET /emoji/{id}` · `GET /e/{id}.webp` · `GET /{id}.webp` — 커스텀 이모지 `160×160` WebP 리사이징 제공
   - `GET /sticker/{id}` · `GET /s/{id}.webp` — 스티커 `160×160` WebP 리사이징 제공
   - 24시간 TTL 인메모리 캐시(`50,000` 엔트리), `ETag: W/"<sha1>"`(`304 Not Modified`), `Cache-Control: public, max-age=86400`, 선택적 `SIGNING_KEY`(`?ex={exp}&hm={hm}` HMAC-SHA256) 검증 지원
