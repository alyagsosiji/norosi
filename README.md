## 🌟 프로젝트 소개

**norosi(노로시)**는 봉화(狼煙, 연기 신호)를 뜻하며, 혼잡한 디스코드 서버에서 관리자와 유저 모두에게 가장 명확하고 따뜻한 이정표가 되어주고자 기획되었습니다. 

단순한 기능 나열을 넘어, **GUI 대시보드 인터랙션**, **Firebase 하이브리드 캐시 저장소**, **Discord Audio DAVE 최신 암호화 엔진**, **VM 터미널 실시간 스트리밍** 등 최상위 엔터프라이즈급 안정성을 기본 내장하고 있습니다.

## ✨ 핵심 기능

### 1. 🧭 올인원 마스터 대시보드 (`/대시보드`, `/메뉴`)
- 명령어 타이핑 없이 드롭다운 탭과 버튼 클릭만으로 봇의 모든 기능을 한눈에 조작하는 인터랙티브 GUI 허브
- 홈, 가챠, 라이프, 음악, 역할, 관리자, 통계 7대 카테고리 즉각 전환 지원

### 2. 🎮 프로젝트 세카이(Project SEKAI) 가챠 & 컬렉션
- **10회 / 1회 뽑기 시뮬레이터:** 한섭 최신 픽업 및 통상 카드 데이터 완벽 연동
- **카드 보관함 및 덱 편성:** 획득한 카드를 확인하고 나만의 5인 덱 구성
- **💎 중복 카드 일괄 환전:** 중복 획득한 카드를 등급별(★4: 100💎, 생일: 60💎, ★3: 25💎, ★2/★1: 5💎) 크리스탈로 원클릭 환전
- **카드 도감 & 랭킹:** 유닛별/캐릭터별 수집률 집계 및 서버 가챠 랭킹보드

### 3. 🎵 스마트 고음질 음악 & 플레이리스트 스튜디오
- **다양한 플랫폼 지원:** YouTube, Spotify 음원 정보, SoundCloud, 직링크 MP3 스트리밍
- **DAVE 음성 엔진 호환:** Discord 최신 종단간 암호화(Discord Audio/Video E2EE) 음성 표준 대응
- **나만의 플레이리스트 스튜디오:** 곡 추가, 순서 편집, 일괄 재생이 가능한 개인 음원 보관함
- **감성 음악 추천 & 440Hz 자가진단:** 분위기 기반 랜덤 추천 및 음성채널 연결/음질 자가진단

### 4. 📅 D-Day 전광판 & 라이프케어 허브
- **D-Day 실시간 전광판:** 음성/텍스트 채널 이름으로 D-Day 자동 카운트다운 갱신
- **자동 알림 & 생일 축하:** 지정 시간에 기념일/시험 D-Day 및 서버원 생일 축하 메시지 발송
- **뽀모도로 집중모드 타이머:** 맞춤 집중/휴식 시간 설정 및 음성채널 자동 알림
- **오늘의 목표(잔디 심기) & 출석체크:** 일일 목표 달성 시 GitHub 잔디 스타일 스트릭 기록 및 크리스탈 보상

### 5. 🎭 반응역할 & 커스텀 버튼 스튜디오
- **이모지 반응역할 스튜디오:** 이모지 클릭으로 역할을 자동 부여/회수하는 반응역할 패널
- **사진 스타일 커스텀 버튼 패널:** 이미지, 제목, 본문, 버튼 이름, 이모지를 자유롭게 구성하는 고품질 버튼 패널 제작

### 6. 🖥️ VM 서버 터미널 실시간 디스코드 채널 브릿지
- **실시간 콘솔 전송:** GCP VM, 리눅스 서버 터미널의 `stdout`, `stderr`, `logging` 출력을 디스코드 지정 채널로 실시간 미러링
- **무한 루프 & 도배 방지:** Discord HTTP 통신 로그 자동 필터링 및 2초 주기 1,850자 묶음 전송으로 Rate Limit 완벽 방어
- **명령어:** `/터미널로그채널 [채널]` (슬래시) 또는 `!터미널로그 #채널` (접두사)

### 7. 📊 서버 이벤트 종합 로깅 & 활동 통계
- 입퇴장, 메시지 수정/삭제, 음성 입퇴장, 채널/역할 변경 등 7대 서버 감사 이벤트 실시간 임베드 기록
- 종합 유저 프로필 카드, 서버 채팅/통화 활동 랭킹, 익명/공개 건의함 모달

### 8. 🤖 프로세카 26인 페르소나 대화형 AI
- 카나데, 미쿠, 미즈키, 마후유 등 프로세카 26인 캐릭터 어조 페르소나 및 맞춤 프롬프트 대화 지원
- 오프라인 감성 폴백 대사 내장으로 외부 AI 장애 시에도 자연스러운 대화 유지

### 9. ⚡ 강력한 시스템 안정성
- **0초 즉시 슬래시 명령어 동기화:** `!싱크` / `!동기화` 버튼형 UI로 디스코드 전역 캐시 지연 없이 즉시 반영
- **자가 치유형 .env 로더:** UTF-8 BOM, 따옴표, 빈값 덮어쓰기 문제 완벽 방어
- **Firebase 하이브리드 캐시 백업:** 로컬 JSON 캐시와 클라우드 원격 DB 실시간 양방향 동기화

## 🚀 빠른 시작 가이드

### 1. 사전 요구사항
- **Python:** 3.10 이상
- **외부 유틸리티:** `ffmpeg`, `yt-dlp` (음악 재생 시 필요)
- **Git**

### 2. 저장소 클론 및 패키지 설치
```bash
# 1. 저장소 클론
git clone https://github.com/alyagsosiji/norosi.git
cd norosi

# 2. 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 필수 패키지 설치
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. 환경 변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 아래 양식에 맞추어 값을 입력합니다:

```env
# [필수] 디스코드 봇 토큰 (Discord Developer Portal에서 발급)
DISCORD_TOKEN="your_bot_token_here"

# [선택] 봇 관리자 유저 ID (우클릭 -> ID 복사)
BOT_OWNER_ID="123456789012345678"

# [선택] Spotify 추천 음악 API (Spotify Developer Dashboard)
SPOTIPY_CLIENT_ID=""
SPOTIPY_CLIENT_SECRET=""

# [선택] Firebase Realtime Database 연동 (원격 클라우드 백업용)
# GCP 로컬 디스크 환경에서는 비워두셔도 로컬 캐시(ddays_data.json)로 안전하게 작동합니다.
FIREBASE_DB_URL=""
FIREBASE_SECRET=""

# [선택] 웹서버 포트 (Render / 헬스체크용)
PORT="10000"
```

### 4. 봇 실행
```bash
python3 bot.py
```

봇이 켜지면 관리자 권한이 있는 디스코드 채널에서 `!싱크`를 입력하여 슬래시 명령어를 즉시 동기화해 주세요.

## 🌐 서버 배포 (GCP / Linux systemd)

GCP Compute Engine (e2-micro 평생 무료 티어) 또는 일반 우분투/데비안 서버에서 24시간 무중단으로 구동할 수 있도록 전용 배포 스크립트를 제공합니다.

```bash
# 1. GCP 인스턴스 초기 자동 환경 구축 (의존성, venv, ffmpeg, systemd 등록)
bash deploy/setup_gcp.sh

# 2. systemd 서비스 상태 확인
sudo systemctl status norosi.service

# 3. 깃허브 최신 코드 업데이트 및 봇 재기동 (운영 중 원클릭 적용)
bash deploy/update_bot.sh
```
