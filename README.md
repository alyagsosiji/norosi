## 🌟 프로젝트 소개

**norosi(노로시)** 는 봉화(狼煙, 연기 신호)를 뜻하며, 혼잡한 디스코드 서버에서 관리자와 유저 모두에게 가장 명확하고 따뜻한 이정표가 되어주고자 기획되었습니다.

복잡하게 흩어져 있던 수십 개의 슬래시 명령어를 **`/설정`**, **`/도움말`**, **`/후원`** 단 3개로 일원화하고, **컴포넌트 V2 스타일 계층형 내비게이션(일반 · 고급 · 미니게임 · 개인 + 뒤로가기 + 15페이지 통합 페이지네이션 & 번호 바로가기 버튼)**, **개인 커스텀 즐겨찾기 단축바(최대 5개)**, **권한 3단계 완벽 분리(일반 이용자 · 서버 관리자 · 봇 주인)**, **Firebase 하이브리드 비동기 캐시 엔진**, **Discord Audio DAVE E2EE 암호화 엔진**, **배포 전 AST·보안 회귀 CI 검증(`scripts/ci_check.py`)** 등 엔터프라이즈급 안정성과 반응속도를 기본 내장하고 있습니다.

## ✨ 핵심 기능

### 1. ⚙️ 컴포넌트 V2 통합 설정 허브 (`/설정`) · 맞춤형 가이드 (`/도움말`) · 후원 안내 (`/후원`)
- **핵심 슬래시 명령어 3종 통합 (`/설정`, `/도움말`, `/후원`):** 복잡한 명령어 암기 없이 `/설정` 하나로 90개 전체 기능을 버튼·드롭다운·모달만으로 조작합니다. (`!설정`, `!즐겨찾기`, `!도움말`, `!후원` 등 기존 `!` 접두사 단축어도 완벽 호환)
- **컴포넌트 V2 계층형 UI & 15페이지 통합 페이지네이션:**
  - **1단계 (홈):** `[🌐 일반]` · `[⚙️ 고급]` · `[🎮 미니게임]` · `[👤 개인]` 4대 카테고리 버튼 + **⭐ 나만의 홈 즐겨찾기 단축바(최대 5개 커스터마이징)** + 빠른 실행 드롭다운 + 통합 페이지네이션(`1~15p`)
  - **2단계 (카테고리 내부):** 카테고리별 세부 기능 버튼(페이지당 6개) + `[⬅️ 뒤로]` + `[◀ / 📄 현재·통합 / ▶]` + **직접 페이지 번호 점프 버튼**
  - **3단계 (세부 제어판):** 도감·랭킹·티켓·픽업·백업·초기화 등 하위 컨트롤 패널 + `[⬅️ 뒤로]` + `[🏠 설정 홈]`
- **권한 3단계 엄격 분리:** **일반 이용자** (`👤일반`), **서버 관리자 전용** (`🛡️관리자`), **봇 주인 전용** (`👑봇주인`) 권한을 UI 배지와 서버 측 이중 검증으로 철저히 구분합니다.
- **자발적 후원 안내 (`/후원` · `!후원`):** 24/7 서버 호스팅 및 유지 개발을 응원할 수 있는 **Team. 봉화 (소유주 : 아시)** GitHub Sponsors 페이지로 바로 연결됩니다.

### 2. 저장소 클론 및 패키지 설치
```bash
# 1. 저장소 클론
git clone https://github.com/alyagsosiji/norosi.git
cd norosi

# 2. 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 필수 패키지 설치
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. 환경 변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 아래 양식에 맞추어 값을 입력합니다 (`deploy/.env.example.txt` 참고):

```env
# [필수] 디스코드 봇 토큰 (Discord Developer Portal에서 발급)
DISCORD_TOKEN="your_bot_token_here"

# [선택] 봇 주인(소유자) 유저 ID (다중 지정 시 쉼표로 구분하여 BOT_OWNER_IDS 사용 가능)
BOT_OWNER_ID="123456789012345678"
BOT_OWNER_IDS=""

# [선택] 웹서버 포트 (헬스체크 · GitHub 웹훅 · 내장 Emote CDN)
PORT="10000"

# [선택] GitHub Webhook HMAC-SHA256 서명 검증 시크릿 (/api/github/webhook 보안 검증용)
GITHUB_WEBHOOK_SECRET=""

# [선택] emote-cdn-rust 외부 CDN 주소 및 HMAC-SHA256 서명 키
# 미설정 시에도 내장 160x160 WebP 리사이저(포트 10000/53292) 및 공개 WebP CDN 폴백으로 자동 작동합니다.
EMOTE_CDN_BASE_URL="https://cdn.kamibot.app"
SIGNING_KEY=""

# [선택] 외부 접근 호스트 주소 (GitHub 웹훅 안내 및 내장 CDN URL 생성용)
EXTERNAL_URL=""
WEBHOOK_HOST=""

# [선택] Spotify 추천 음악 API (Spotify Developer Dashboard)
SPOTIPY_CLIENT_ID=""
SPOTIPY_CLIENT_SECRET=""

# [선택] Firebase Realtime Database 연동 (원격 클라우드 백업용)
# 로컬 디스크 환경에서는 비워두셔도 로컬 캐시(ddays_data.json)로 안전하게 작동합니다.
FIREBASE_DB_URL=""
FIREBASE_SECRET=""
```

### 4. 사전 점검 및 봇 실행
```bash
# (선택) 배포 전 구문·AST·보안 가드 자동 검증 실행
```

## 🔍 이모지 업스케일 CDN (`emote-cdn-rust` 가이드 호환)

`cogs/emoji_upscale.py` 모듈은 [Kamilake/emote-cdn-rust](https://github.com/Kamilake/emote-cdn-rust) 프로젝트의 아키텍처와 가이드를 준수하여 구현되었습니다:

1. **투명 여백 없는 160×160 종횡비 유지 리사이징:**
   - 투명 캔버스 패딩을 사용하지 않고, 원본 이모지·스티커의 가로세로 비율(`aspect_ratio = width / height`)을 100% 보존하여 `160×160` 박스 내 최대 크기로 `Lanczos3` 리사이징 후 정적/애니메이션 `WebP`로 인코딩합니다.
2. **모바일 & 데스크탑 종횡비 완벽 호환 & 웹훅 아바타 자동 복구:**
   - 파일 첨부 시 모바일 가로 100% 확대 현상을 방지하기 위해 `HTTP 200 OK` 검증된 `.webp` CDN 마스킹 링크(`[⠀](url)`) 언펄 방식을 사용하며, 웹훅 아바타 깨짐 감지 시 Clean CDN → `wsrv.nl` → 직접 PNG 업로드(`webhook.edit`) 순으로 자동 복구합니다.
3. **내장 HTTP CDN & 웹훅 엔드포인트 (포트 `PORT`(기본 `10000`) 및 `53292`):**
   - `GET /` · `GET /healthz` — 서버 상태 확인 (`ok`)
   - `GET /cdn` — 내장 Emote CDN 안내 페이지
   - `GET /emoji/{id}` · `GET /e/{id}` · `GET /{name}` — 커스텀 이모지 `160×160` WebP 리사이징 제공
   - `GET /sticker/{id}` · `GET /s/{id}` — 스티커 `160×160` WebP 리사이징 제공
   - `POST /api/github/webhook` · `/github/webhook` · `/webhook/github` · `/github` — GitHub 푸시/배포 알림 웹훅 수신 (`GITHUB_WEBHOOK_SECRET` 서명 검증)
   - 24시간 TTL 인메모리 캐시(`50,000` 엔트리), `ETag: W/"<sha1>"`(`304 Not Modified`), `Cache-Control: public, max-age=86400`, 선택적 `SIGNING_KEY`(`?ex={exp}&hm={hm}` HMAC-SHA256) 검증 지원

- **무저장 실시간 중계:** 음악 및 플레이리스트 기능은 YouTube, Spotify, SoundCloud 등 외부 플랫폼의 공개 스트림/메타데이터를 실시간 중계할 뿐, **저작권이 있는 음원 파일을 서버 디스크에 영구 저장·무단 복제·재배포하지 않습니다.**
- **SNS 링크 미리보기:** 다중 SNS 링크 보정 기능은 사용자가 공개 채널에 공유한 공개 게시물 URL의 메타데이터·미디어를 실시간으로 표시하는 편의 기능이며, 원 게시물의 권리는 원작자와 각 플랫폼에 귀속됩니다.
- **이용자 준수 의무:** 사용자는 각 플랫폼의 이용약관 및 저작권법을 준수할 책임이 있으며, 불법 복제물이나 저작권 침해 콘텐츠를 유포하는 용도로 본 봇을 악용해서는 안 됩니다.

### 4. 공공·생물 및 기상 데이터 면책 고지
